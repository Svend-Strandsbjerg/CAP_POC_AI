# Repository Working Rules

- Implement only the explicitly provided task scope.
- Never modify `main` directly.
- Use short-lived branches and pull requests.
- Do not introduce architecture changes without human approval.
- Keep changes small and reviewable.
- Provide factual test evidence for completed work.
- Do not add UI, CI/CD, BTP, authentication, integrations, or production concerns unless explicitly authorized.
- Do not copy ABAP structure mechanically into CAP.
- Do not commit secrets or environment files.
